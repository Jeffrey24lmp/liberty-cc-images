# Liberty CC images

Pictures uploaded from the Liberty Command Centre (Tools > Image library), for use in emails, proposals and pages.

**This repo is public.** Anyone can list and open every picture here, not only people who were sent a link, and git history keeps
every picture ever added, including removed ones.

- Files are added only by the Command Centre, through a key that can write to this one repo.
- Every picture is redrawn before upload: no camera details or location, at most 2,400 pixels a side.
- Names are the first 16 characters of the picture's own SHA-256, so a name says nothing about who uploaded it or what it shows.
- `cc/` holds the live site's uploads; `test/` holds test uploads.
- Addresses used in emails are pinned to the commit that added the picture, for example
  `https://raw.githubusercontent.com/Jeffrey24lmp/liberty-cc-images/<commit>/cc/2026/11/<name>.jpg`, so they never change.

Do not upload private documents, contracts, IDs or screenshots with personal details.
